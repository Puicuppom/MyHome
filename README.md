# MyHome

เว็บแอปส่วนตัว (PWA) 2 ส่วน
- **ผ่อนบ้าน** — คำนวณระยะเวลา/ดอกเบี้ย, ดอกเบี้ยหลายช่วง, เทียบ "ผ่อนปกติ" กับ "ผ่อน + โปะ" (โปะรายเดือน + โปะก้อน), กราฟยอดคงเหลือ/ดอกเบี้ยสะสม, ตารางรายปี/รายเดือน
- **เงินได้** — เงินเดือน/โบนัส/40(2) พร้อมภาษีหัก ณ ที่จ่าย และประกันสังคมจากสลิป (ทำซ้ำทุกเดือนได้)
- **ลดหย่อน** — รายการลดหย่อนพร้อมเพดาน, ดึงดอกเบี้ยบ้านจากหน้าผ่อนบ้าน
- **ค่าเช่า** — บันทึกเงินค่าเช่าที่ได้รับ (40(5)) สรุป ภ.ง.ด.94 (ม.ค.–มิ.ย.) และ ภ.ง.ด.90 (ทั้งปี) พร้อมประมาณภาษี, ส่งออก CSV

ข้อมูลเก็บใน Supabase (โปรเจกต์เดียวกับ PuiJod) ล็อกอินด้วยอีเมล/รหัสผ่าน และเปิด RLS ให้แต่ละบัญชีเห็นเฉพาะข้อมูลตัวเอง

## ติดตั้งครั้งแรก
1. Supabase → SQL Editor → รันไฟล์ `supabase/schema.sql` (ติดตั้งใหม่) หรือรัน `002_salary.sql`, `003_income_deduction.sql` ที่ยังไม่เคยรัน
2. GitHub → Settings → Pages → Source: Deploy from branch `main` / root

## โครงสร้าง
```
index.html        หน้าเดียว (#loan, #rent)
css/app.css
js/core.js        Supabase client, login, routing
js/loan.js        ผ่อนบ้าน
js/tax.js         ข้อมูลร่วม + คำนวณ ภ.ง.ด.94/90
js/income.js      เงินได้
js/rent.js        ค่าเช่า
js/deduct.js      ลดหย่อน
supabase/schema.sql
```
